# Maintenance: preserve a fictional curator's notes

This is a newly written illustrative walkthrough, not an execution record or
anonymized personal case. Every museum detail and note is invented.

Moonseed Museum already has a small label-export command. A volunteer reports
that some distinct accessions disappear. The visible ordinary test passes.
Dumbcane routes the task to investigation and a bounded repair, preserving
existing content and meaningful assertions. A whole-product selection review
is unnecessary for this requested behavior fix.

The agent must reproduce the actual loss, repair the behavior and run relevant
checks. The independent controller then checks fresh catalogs and confirms
that the fictional curator note and display settings remain byte identical.
An ordinary green test before the repair does not prove the bug is absent.

Stage with `python3 -B evals/stage.py maintenance NEW_DIR` and use the
[evaluation guide](../../evals/README.md) for external acceptance.
