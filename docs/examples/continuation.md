# Continue an approved fictional task

This is a newly written illustrative walkthrough, not an execution record or
anonymized personal case. The decision is synthetic input for this example.

The fictional Moonseed Museum user explicitly approves a small Python
standard-library label command with a precise JSON interface. That current
approval applies to the supplied scope. Awesome Workflow carries it into implementation
and verification without asking the same route question again or inventing a
previous research session.

The user expects a runnable command, tested label output, readable input errors
and a truthful account of verification. Publishing, installing external tools
and changing unrelated user files are outside this task.

Stage with `python3 -B evals/stage.py continuation NEW_DIR`. The
[evaluation guide](../../evals/README.md) keeps the actual acceptance checks
separate from the agent's input.
