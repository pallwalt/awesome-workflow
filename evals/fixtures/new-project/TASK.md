# Synthetic task: discuss a new specimen-label tool

This is an invented task for the fictional Moonseed Museum. No real museum or
personal project is represented.

We want a local command that turns a small JSON catalog into print-ready label
data. A record contains an accession, a title and a collection. We care about
simple operation by volunteers and keeping catalog data on our computer. We
have not chosen whether to adopt an existing tool, reuse a small library or
write a tiny command ourselves.

First understand the goal and compare available GitHub projects. Consider both
complete tools and useful smaller parts. Give a bounded recommendation with
tradeoffs and links that distinguish repository claims, inspected source and
anything actually run. Preserve uncertainty where evidence is missing. Ask us
to choose the overall route before implementation; do not create product code,
initialize a repository, clone, install or execute a candidate yet. We have
not approved a product route in this task.

Use this directory for any concise research/decision note you need. No catalog
data or implementation is supplied. If browsing is unavailable, say so and
explain the unresolved choice without pretending the search happened.
